# Bhavish Jan

This repository contains the source code for my personal GitHub Pages website.

## Live Website

[bhavishjan.github.io](https://bhavishjan.github.io)

## About

The website is a personal portfolio and landing page with:

- a custom hero section
- dark mode support
- animated UI elements
- education, skills, and contact sections

## Tech Stack

- HTML
- CSS
- JavaScript

## Local Development

Clone the repository and open `index.html` in your browser, or serve the project with any simple static server.

## Notes

Local editor and IDE workspace files are ignored through `.gitignore`.
